🧠 Генерация расписания
Отдельная рабочая зона для preview, анализа bucket’ов, генерации расписания и просмотра итоговых групп с кликабельными связями на курс, преподавателя, аудиторию и студентов.
Базовые операции Поиск и связи Генерация расписания
Что здесь можно делать
Считать preview без записи в базу, смотреть bucket’ы приоритизации, запускать реальную генерацию и анализировать итоговый план по карточкам.
Режим
Planner
Bucket debug
Да
API
/api
Типовой сценарий
1) Запустить preview → 2) посмотреть маленькие группы и нераспределённых → 3) открыть bucket’ы → 4) убедиться в результате → 5) только потом нажать generate.
Доступ ограничен
Генерация расписания доступна только менеджеру или администратору.
Параметры генерации
Укажи учебный год и минимальный размер группы.
Готов к расчёту
Сводка
Общее количество заявок, распределённых и нераспределённых.
Предупреждения
Маленькие группы и другие важные моменты распределения.
Статистика по курсам
Сколько детей распределено и сколько осталось вручную.
Итоговые группы
Кликабельные карточки групп. Нажми на карточку, чтобы открыть детали справа.
Нераспределённые заявки
Эти заявки остаются pending для ручной работы сотрудников.
Bucket’ы и приоритизация
Спрос, rigid-дети и очередь обработки временных окон.
Детали
Карточка preview-группы, bucket’а или сущности из базы.
